# REQ-FUNC-021 — полный экспорт и восстановление данных обучения

- **Тип:** функциональное требование
- **Приоритет:** 10 для плана v0.3
- **Статус:** добавлено по CR-002 в ЛР4; требуется включить в следующую редакцию SRS
- **Компонент:** модуль переноса данных
- **Связанные требования:** REQ-FUNC-006, REQ-SEC-001, REQ-REL-002

## Требование

Система должна позволять авторизованному учащемуся скачать полный версионируемый экспорт своих данных в формате JSON и восстановить данные из файла на поддерживаемой установке LinguaLoop. Полный экспорт включает курсы, колоды, карточки, параметры расписания SM-2, журнал повторений, дневные цели, настройки и состояние серии. Он не должен включать пароль, токены сессии или секреты SMTP.

До изменения данных система должна проверить читаемость, версию формата, обязательные поля и согласованность ссылок. Перед заменой данных текущей учётной записи система показывает предупреждение и запрашивает подтверждение. Импорт должен применяться транзакционно: при ошибке текущие данные остаются неизменными. Функция REQ-FUNC-006 продолжает использовать CSV только для карточек.

## Обоснование

Учащийся должен иметь возможность перенести накопленный словарь и прогресс, включая расписание и историю ответов. CSV-экспорт карточек не сохраняет состояние SM-2, цели и серии.

## Критерии приёмки

1. Пользователь может скачать файл, содержащий карточки, курсы, расписание, журнал повторений, цели, настройки и серию.
2. Импорт корректного файла в отдельную учётную запись восстанавливает записи и прогресс, а контрольные показатели совпадают с исходными.
3. До подтверждения замены система показывает, что будет заменено, и запрашивает явное подтверждение.
4. Повреждённый файл, неверная структура и неизвестная версия отклоняются с понятным сообщением.
5. При ошибке записи или прерывании импорта исходное состояние учётной записи сохраняется целиком.
6. Импорт нельзя применить к чужой учётной записи; пароль, сессионные токены и SMTP-секреты в файл не попадают.
7. Проверка включает обычный файл, повреждение, неизвестную версию и сбой транзакции.

## Вне объёма

Автоматическая синхронизация между устройствами, облачное хранение файлов, слияние двух экспортов и миграция неподдерживаемых версий формата.

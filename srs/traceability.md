# Матрица требований и проектных связей

Исходный базис — SRS 0.2 из ЛР3. REQ-FUNC-022 сохраняет свой исходный смысл о сводке по статусам; новая функция резервирования получает отдельный ID REQ-FUNC-023.

| Требования | Решение | Проверка |
|---|---|---|
| REQ-FUNC-001–005, 019 | CatalogService и SQLite-репозиторий | Операции с книгами, данные после перезапуска |
| REQ-FUNC-006–013 | Поисковая служба и параметры запроса | Поиск, фильтры и порядок выдачи |
| REQ-FUNC-014–018, 021 | ProgressService и правила Book | Границы страницы, восстановление места чтения |
| REQ-FUNC-020 | Нормализация ISBN | Дубликат распознан, отмена доступна |
| REQ-FUNC-022 | Сводка количества книг по статусам | Перенесена CR-001 за пределы первой версии |
| REQ-FUNC-023 | BackupService | Создание и восстановление копии, отказной сценарий |

## Базовые версии

- SRS 0.2: 22 функциональных требования и 10 ключевых требований качества из ЛР3.
- CR-001: REQ-FUNC-022 оставлено под прежним ID, но отложено.
- CR-002: добавлено требование REQ-FUNC-023.

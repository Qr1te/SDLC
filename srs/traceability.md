# Матрица трассируемости LinguaLoop (ЛР4)

Базовый документ — SRS LinguaLoop v0.2 из ЛР3. REQ-FUNC-001–020 сохранены. Изменение CR-001 переносит REQ-FUNC-012 и REQ-FUNC-014 за пределы первого выпуска, не удаляя их из спецификации. CR-002 добавляет REQ-FUNC-021; требование оформлено отдельным delta-документом для последующего включения в SRS.

| Требования | Решение | Проверка |
|---|---|---|
| F01, F15 | Модуль доступа и настроек, Spring Security | регистрация, вход, значения и часовой пояс |
| F02–F06, F13 | Каталог курсов, колод и карточек | операции каталога, текст, CSV, поиск и фильтры |
| F07–F08 | Планировщик SM-2 и сеанс повторения | контрольные примеры, журнал, прерывание сеанса |
| F09–F10, F17–F19 | Цели, серии, заморозка, экран «Сегодня», предупреждение | границы дня, серия, лимиты и показатели экрана |
| F11–F12 | Статистика и прогноз | выборочные периоды и совпадение с журналом; F12 отложено по CR-001 |
| F14 | SMTP-напоминания | отключение, выполненная цель, лимит одного письма; F14 отложено по CR-001 |
| F20 | Озвучивание через Web Speech API | доступность кнопки и отсутствие сохранения аудио |
| F21 | JSON Export/Import-сервис | Сверка EF, интервала, даты повтора и журнала после round-trip; чужая учётная запись; повреждённый файл; неизвестная версия; сбой транзакции без изменения исходных данных |

## История изменений

- **SRS v0.2:** 20 функциональных требований после рецензирования ЛР3.
- **CR-001:** F12 и F14 перенесены из v1.0; приоритеты и план обновлены в v0.2.
- **CR-002:** добавлено F21; план и архитектурное решение обновлены в v0.3.

## Связь с бизнес-целями ЛР3

- **БЦ-1 (регулярность занятий):** F09, F10, F17, F18, F19.
- **БЦ-2 (быстрое создание карточек):** F04, F05, F06.
- **БЦ-3 (удержание знаний):** F07, F08, F11, F16.
- **Перенос прогресса:** F21 сохраняет данные, на которых основаны указанные цели.

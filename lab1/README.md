# Лабораторная работа №1 — Вариант 10
«Утилита для информирования пользователя о нормальном артериальном давлении»

Язык: **Java** (Swing), архитектура: **MVC с активной моделью**.

## Структура проекта

```
src/by/bsuir/lab1/
 ├── Main.java                     — точка входа
 ├── model/
 │    ├── PressureModel.java       — активная модель (валидация + расчёт + уведомление View)
 │    └── InvalidInputException.java
 ├── view/
 │    ├── MainFrame.java           — главная форма
 │    └── InputDialog.java         — окно ввода данных (дата рождения из 3 JComboBox, вес, давление)
 └── controller/
      └── Controller.java         — обработка событий кнопок, передача данных модели
```

## Как это работает

1. Главная форма содержит кнопку **«Ввести данные»**.
2. По нажатию открывается модальное окно ввода: дата рождения (день/месяц/год —
   обычные `JComboBox`, стандартный компонент выбора даты **не используется**),
   вес и текущее давление (верхнее/нижнее).
3. При повторном открытии окна ввода в нём восстанавливаются последние введённые значения
   (хранятся в модели).
4. Контроллер передаёт введённые "сырые" данные модели. **Модель** (а не контроллер и не
   представление) сама:
   - проверяет корректность даты, веса и давления;
   - при ошибке выбрасывает `InvalidInputException` с понятным текстом — контроллер
     показывает его пользователю через `JOptionPane`;
   - при успехе вычисляет возраст, "должное" (идеальное) давление по формуле Волынского
     и оценку текущего давления (норма / повышенное / пониженное);
   - уведомляет главную форму о готовых данных через `PropertyChangeListener`
     (это и есть **активная модель** — модель сама "толкает" изменения во View,
     а не View дергает модель за геттерами по таймеру или по запросу контроллера).
5. Главная форма отображает последние введённые данные и результат расчёта.

Формула "должного" давления (формула Волынского), учитывающая возраст и массу тела:

```
SBP_ideal = 109 + 0.5 × возраст + 0.1 × вес(кг)
DBP_ideal = 63  + 0.1 × возраст + 0.15 × вес(кг)
```

Текущее давление сравнивается с идеальным с допуском ±10 мм рт. ст.

## Сборка и запуск

Требуется JDK 11+ (используются только стандартные `javax.swing` и `java.time`,
внешних зависимостей нет).

```bash
cd src
javac by/bsuir/lab1/Main.java by/bsuir/lab1/model/*.java by/bsuir/lab1/view/*.java by/bsuir/lab1/controller/*.java
java by.bsuir.lab1.Main
```

Или через IntelliJ IDEA / Eclipse / VS Code (Extension Pack for Java):
1. Открыть папку `src` как исходный корень (Source Root) нового Java-проекта.
2. Запустить класс `by.bsuir.lab1.Main`.

## О MVC с активной и пассивной моделью (для отчёта)

- **Активная модель** (реализовано здесь): модель сама содержит логику валидации
  и расчётов и сама уведомляет представление об изменениях (через слушателей/события).
  View подписывается на модель и пассивно перерисовывается, когда модель "сообщает",
  что данные изменились.
- **Пассивная модель**: модель — это просто хранилище данных (геттеры/сеттеры,
  без валидации и без уведомлений). Всю работу выполняет контроллер: он получает
  данные из View, сам их проверяет и вычисляет результат, кладёт результат в модель,
  а затем сам, явно, обновляет View. Модель в этом случае ничего не знает
  о представлении и не уведомляет его.
- **Контроллер, совмещённый с пассивной моделью** (для "совсем неуспевающих"):
  отдельного класса модели фактически нет — поля состояния и методы расчёта/валидации
  переносятся прямо в контроллер, который одновременно играет роль модели.

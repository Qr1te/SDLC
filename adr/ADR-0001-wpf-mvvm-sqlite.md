# ADR-0001: WPF, MVVM и локальная SQLite

- **Статус:** принято для проектного варианта
- **Дата:** 2026-11-15
- **Связи:** функциональные требования REQ-FUNC-001–022; ограничения по совместимости, скорости и сохранности

## Контекст

BookShelf — персональный каталог для Windows. Программа должна запускаться локально, сохранять изменения между сеансами и быстро находить записи без обязательного сетевого соединения. Ресурсы разработки и срок ограничены рамками учебного проекта.

## Критерии

- работа на Windows 10/11;
- простой запуск и невысокая стоимость сопровождения;
- надёжная запись каталога;
- отдельное тестирование правил прогресса;
- отсутствие серверной инфраструктуры для одного пользователя.

## Альтернативы

| Вариант | Преимущества | Недостатки |
|---|---|---|
| WPF + MVVM + SQLite | Локальный режим, разделение UI и логики, небольшая инфраструктура | Платформа ограничена Windows; схему БД нужно сопровождать |
| Веб-клиент и серверная БД | Доступ с нескольких устройств | Нужны сервер, сеть, учетные записи и эксплуатация |
| Табличный файл | Быстрый начальный прототип | Сложнее обеспечить целостность, поиск и безопасные обновления |

## Решение

Применить WPF с разделением MVVM и хранить каталог в SQLite. View вызывает команды ViewModel, а ViewModel использует сервисы. Работа с книгами проходит через IBookRepository. Правила ISBN и прогресса не должны зависеть от конкретного экрана.

## Последствия

**Положительные:** локальный запуск без сервера; понятное разделение ответственности; простые транзакции и демонстрация приложения.

**Отрицательные:** приложение привязано к Windows; перенос каталога требует отдельного механизма; изменение структуры SQLite требует контролируемой миграции.

**Нейтральные:** резервирование реализуется отдельным BackupService; многопользовательский режим и облачная синхронизация остаются за границами.

## Условия пересмотра

Повторно оценить решение при появлении требования к macOS/Linux, совместной работе нескольких пользователей или сетевой синхронизации.

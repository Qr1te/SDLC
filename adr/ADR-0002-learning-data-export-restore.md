# ADR-0002: Версионируемый перенос данных обучения

- **Статус:** принято в рамках плана v0.3
- **Дата:** 2026-11-15
- **Проект:** LinguaLoop, версия 1.0
- **Связанные требования:** REQ-FUNC-006, REQ-FUNC-021, REQ-SEC-001, REQ-REL-002

## Контекст

REQ-FUNC-006 переносит карточки колоды в CSV, но не сохраняет расписание SM-2, журнал повторений, курсы, настройки и серии занятий. Заказчик просит переносить обучение целиком на другую установку LinguaLoop. Ошибка импорта не должна оставлять частично изменённые данные.

## Решение

Добавить отдельный JSON-файл полного экспорта с номером версии формата. Включать курсы, колоды, карточки, параметры SM-2, журнал повторений, дневные цели, настройки и связанные данные серии. Экспорт выполняется для авторизованной учётной записи. Импорт сначала проверяет размер, структуру, версию, обязательные поля и согласованность ссылок, затем показывает сводку и просит подтверждение.

После подтверждения импорт выполняется транзакционно и заменяет данные только текущей учётной записи. При ошибке транзакция откатывается. CSV остаётся средством обмена карточками и не заменяет полный экспорт. Импорт неподдерживаемой версии отклоняется; автоматическая миграция старых экспортов в первой версии не обещается.

## Рассмотренные варианты

| Вариант | Преимущества | Недостатки |
|---|---|---|
| JSON с версией формата | Читаемая структура, легко валидировать и переносить | Нужно поддерживать контракт формата |
| CSV для всего состояния | Удобен для таблиц | Неудобно представить связи и историю повторений |
| Копирование файла БД | Быстро для локальной установки | PostgreSQL — серверная БД; файл не переносим между учётными записями и версиями схемы |

## Последствия

- Формат экспорта документируется и тестируется на обратимость.
- В экспорт не включаются пароли, токены сессий и секреты SMTP.
- Доступ к скачиванию и загрузке требует аутентификации и проверки владельца данных.
- Для REQ-FUNC-021 нужны проверки корректного файла, повреждённого файла, неизвестной версии и сбоя транзакции.
